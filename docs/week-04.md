## ① 주제 선택 / Choosing one problem

| 항목 Item | 내용 |
|---|---|
| 선택한 주제 Chosen | 학생식당·푸드코트 등 대기열이 필요한 줄의 “예상 대기시간 안내”. 카메라로 대기 구역 인원과 배식구 통과 인원을 세어 "지금 서면 몇 분 걸리는지"를 보여준다. |
| 선택 근거 Why | 대기 인원과 처리 속도가 눈에 보이는 물리량이라 측정과 검증이 가능하다. 세탁기·주차장은 학교 부서 협조가 없으면 실데이터를 얻기 어렵다. 기존 학생 서비스는 메뉴와 시간표를 나열할 뿐 대기시간을 알려주지 않는다. |

> 세탁실 가상 대기열, 셔틀 대기줄은 같은 자원 모델 위에 어댑터로 확장한다. 이번 주 명세 대상은 학식 한 가지로 한정한다.

## ② 성공 기준 가져오기 / Success criteria from Week 3

| 3주차 성공 기준 원문 Original (Week 3) | 모호한 표현 Vague words |
|---|---|
| 학생들이 학식에 가기 전에 혼잡도를 쉽게 확인할 수 있다 | 쉽게, 혼잡도, 확인할 수 있다, 가기 전에 |
| 줄이 길면 다른 식당을 선택할 수 있다 | 길면, 다른 식당, 선택할 수 있다 |

**모호함을 없앤 재작성**
- "혼잡도" → 대기 구역 인원(명)과 예상 대기시간(분)
- "쉽게 확인" → 앱 첫 화면에서 탭 1회 이내로 해당 식당의 수치 확인
- "줄이 길면" → 예상 대기시간이 기준값(10분) 이상일 때
- "가기 전에" → 측정 시각이 현재로부터 60초 이내인 값
## ③ Acceptance Criteria

| # | 경로 Path | EARS 문장 Sentence | 판정 방법 How to check |
|---|---|---|---|
| AC-1 | 정상 Normal | WHEN 카메라가 학생식당 줄의 인원과 분당 처리 인원을 측정하면 THE 시스템은 SHALL 예상 대기시간(줄 인원 ÷ 분당 처리 인원)을 10초 이내에 이용자 화면에 표시한다 | 점심시간에 팀원 1명이 줄 인원을 직접 세고 1분간 배식받아 나가는 인원을 스톱워치로 센 뒤 손으로 대기시간을 계산. 같은 시각 앱에 표시된 값과 비교하고, 줄이 눈에 띄게 늘거나 줄었을 때 화면이 10초 안에 바뀌는지 휴대폰 시계로 확인 |
| AC-2 | 정상 Normal | WHEN 세탁기 진동이 30초 이상 계속되면 THE 시스템은 SHALL 해당 기기를 "사용 중"으로 표시한다 | 실제 세탁기에 센서를 붙이고 세탁을 시작. 시작 후 20초 시점에는 여전히 "사용 가능", 30초가 지난 뒤 "사용 중"으로 바뀌는지 스톱워치와 앱 화면을 나란히 두고 확인 |
| AC-3 | 실패 Failure | IF 카메라 기기가 숫자 대신 영상이나 이미지를 서버로 보내려 하면 THEN THE 시스템은 SHALL 그 데이터를 받지 않고 어떤 영상·이미지도 저장하지 않는다 | 시연 전 카메라 노트북의 네트워크 전송량을 확인해 숫자 수준의 작은 데이터만 나가는지 점검. 서버 저장 공간을 열어 사진·영상 파일이 하나도 없는지 확인. 일부러 이미지를 붙여 보낸 요청이 거부 안내를 받는지 확인 |
| AC-4 | 정상 Normal | WHEN 대기자가 있는 세탁기가 비면 THE 시스템은 SHALL 대기열 1순위 이용자에게 5초 이내에 알림을 보낸다 | 팀원 A가 앱으로 세탁기에 줄을 서고 앱을 닫음. 팀원 B가 세탁을 끝내 기기가 비는 순간부터 스톱워치를 재고, A의 휴대폰에 5초 안에 "내 차례" 알림이 오는지 확인 |
| AC-5 | 실패 Failure | IF 호출된 이용자가 5분 안에 기기를 사용하지 않으면 THEN THE 시스템은 SHALL 그 호출을 취소하고 다음 순번 이용자에게 알림을 보낸다 | 팀원 A·B가 차례로 줄을 섬. 기기가 비어 A가 호출되면 A는 일부러 아무것도 하지 않음. 5분이 지난 뒤 A의 순번이 사라지고 B의 휴대폰에 호출 알림이 오는지 스톱워치로 확인 |
| AC-6 | 실패 Failure | IF 같은 이용자가 같은 장소에 10분 안에 혼잡도를 다시 제보하면 THEN THE 시스템은 SHALL 두 번째 제보를 받지 않고 다음 제보가 가능한 시각을 안내한다 | 휴대폰 한 대로 학생식당 혼잡도를 제보한 직후 다시 제보. 두 번째는 거절되고 "몇 시 몇 분부터 가능" 안내가 나오는지 확인. 10분이 지난 뒤에는 다시 제보가 되는지 확인 |
