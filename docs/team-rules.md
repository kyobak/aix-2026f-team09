# 팀 규칙 / Team Rules

1주차 활동지(week-01.md)에서 합의한 내용을 여기에 정리합니다.
Copy the agreements from week-01.md here.

1. **연락은 카톡, 응답은 하루 안에.**
   팀장 공지에는 확인 후 체크 표시로 답하고, 개인 수행 과제도 하루 안에 끝낸다.
   마감 24시간 이내 긴급 건은 2시간 내 응답, GitHub 리뷰 요청은 24시간 내 처리.

2. **회의는 수업 직후 60분 고정, 팀 내부 마감은 실제 마감 하루 전.**
   불참은 24시간 전 통보하고 회의록을 읽어 24시간 내 의견을 남긴다.
   못 지킬 것 같으면 마감 전에 알린다 — 늦는 것보다 늦는다는 말을 늦게 하는 것이 문제다.

3. **주당 커밋 3회 · PR 1건 · 리뷰 코멘트 1개 이상.**
   활동지에서 본인이 맡은 항목은 직접 작성한다.
   기여 확인은 기억이 아니라 GitHub 커밋·PR 기록으로 한다.

4. **AI 사용은 자유, 기록은 의무.**
   주요 판단은 `PROMPTS.md`에 남긴다 — 무엇을 물었고 / 무엇을 받았고 / 무엇을 고쳤고 / 왜.
   **이해하지 못한 코드는 PR로 올리지 않는다.** PR 설명에 그 코드가 무엇을 하는지 본인 말로 3줄 쓴다.
   실제 개인정보(학번·연락처·실명)는 AI에 넣지 않고, 외부 코드는 출처를 남긴다.

5. **의견이 갈리면 근거로, 기록 언어는 영어와 한국어를 나눠서.**
   근거 3줄 → 30분 타임박스 실험 → 그래도 갈리면 다수결하되 **반대 의견도 함께 기록한다.**
   회의는 한국어, 커밋·브랜치·이슈 제목은 영어, 문서 본문은 한국어.
